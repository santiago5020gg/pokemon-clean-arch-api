# Prompts

GenAI prompts used to build this project, kept in **English** for the exercise's
**"Generative AI tools"** deliverable.

Each file documents one step of the work:

- **Prompt** — the instruction given to the AI coding tool (Claude Code).
- **Context** — what the AI had access to (files, browser, etc.).
- **Validation** — how the AI's output was checked.
- **Refinements** — how the output was corrected or improved.
