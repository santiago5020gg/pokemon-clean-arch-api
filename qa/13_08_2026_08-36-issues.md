# QA Issues — 2026-08-13 08:36

Full-regression session against the Pokédex web app (`http://localhost:5173`,
backend `http://localhost:8080`), driven as an end user with the Playwright MCP.
Use cases: `qa/use_cases.md`.

**Overall:** the application behaved well. All core user journeys — browse, view
detail, register, log in/out, session persistence, auth-gated writes, edit (with
validation and persistence), delete confirmation, and PokeAPI sync — work. No
functional/correctness defects were confirmed. Findings below are UX/feedback
improvements, one testing-environment caveat, and coverage gaps.

Severity: Blocker · High · Medium · Low · Info.

## ISSUE-01 — [Info · testing environment, NOT a product bug] Playwright MCP browser stops delivering input mid-session

- **Steps to reproduce:** Drive the app through the Playwright MCP for ~2–3 minutes /
  many interactions. After a point, `browser_click` and `browser_press_key` (real
  mouse/keyboard) stop triggering React `onClick` handlers (card navigation, Edit,
  Replicate, Sign out all appear to "do nothing"), while the page renders fine.
- **Expected:** Automated clicks keep activating handlers for the whole session.
- **Actual:** Trusted input events stop reaching handlers. Proven NOT to be a product
  bug: programmatic `element.click()` and a full synthetic pointer sequence both
  navigate correctly, and `browser_close` + reopen fully restores real clicks (a
  fresh browser clicked cards/Edit/Delete/Replicate reliably).
- **Root cause:** MCP/Chromium input-injection degradation in this environment, not
  the app.
- **Action for QA:** when clicks stop registering, **restart the MCP browser**
  (`browser_close`, then navigate again). Do not file app bugs from these symptoms.
- **Evidence:** `.playwright-mcp/card-click-no-nav.png`; a fresh browser then
  navigated `View Bulbasaur` → `/pokemon/1` on the first click.

## ISSUE-02 — [Low · UX] "Replicate from PokeAPI" gives no confirmation, progress, or success feedback

- **Steps to reproduce:** Log in → on `/` click **Replicate from PokeAPI**.
- **Expected:** Some feedback for a bulk data operation — a confirm prompt, a loading
  spinner while syncing, and/or a success toast ("Replicated 20 Pokémon").
- **Actual:** No confirmation and no progress/success indicator. The list silently
  jumps from 3 to 20 Pokémon (#001–#020). A user can't tell it's working, whether it
  finished, or how many were synced; a slow PokeAPI call would look like a dead button.
- **Impact:** Confusing for a data-mutating action; risk of double-clicks / repeated syncs.

## ISSUE-03 — [Info · UX] "Filter this page" only filters the currently loaded page

- **Steps to reproduce:** On `/`, type a name in the search box.
- **Expected (documented by the label):** it filters the current page client-side.
- **Actual:** Works as labeled, but once pagination exists a user searching for a
  Pokémon not on the current page will see "no match" and may assume it doesn't exist.
- **Suggestion:** Consider server-side search across all pages, or make the
  page-scoped limitation more obvious.

## ISSUE-04 — [Info] Handled API errors are logged to the browser console

- **Steps to reproduce:** Attempt a bad login, or open `/pokemon/99999`.
- **Actual:** Console shows `401 (Unauthorized)` / `404 (Not Found)` for the failed
  API calls.
- **Assessment:** Not a defect — the app handles both gracefully (error alert / "not
  found" state). Logged only so console-error monitoring/tests aren't surprised by them.

## Environment notes (not app issues)

- A native **PostgreSQL 17** Windows service already listens on `:5432`, shadowing the
  Docker `db` container's `5432` mapping, so the host-run backend hit the wrong
  Postgres and failed auth (`password authentication failed for user "pokedex"`). QA
  ran the container on host port **5433** and pointed the backend at it
  (`SPRING_DATASOURCE_URL=jdbc:postgresql://localhost:5433/pokedex`). Consider
  documenting this conflict, or having `start-dev` detect/relocate the port.
- Data was mutated during testing: **Replicate** grew the catalog from 3 to 20
  Pokémon (seed no longer pristine). Edits to Bulbasaur were reverted to originals.
